
A companhia de saneamento da cidade lançou uma campanha de conscientização ambiental e precisa classificar o perfil de consumo dos imóveis e emitir alertas educativos aos moradores.

💧 Classificação de Consumo de Água


💧 Sobre o projeto

Este projeto consiste em um programa desenvolvido em Python para classificar o perfil de consumo de água de imóveis e apresentar mensagens educativas aos moradores.

O sistema solicita o tipo de imóvel — comercial, casa ou apartamento — e o consumo mensal de água em metros cúbicos (m³). 

A partir dessas informações, o programa utiliza o comando match/case para aplicar as regras de classificação.

🌱 Objetivo de Conscientização


O consumo consciente de água é uma atitude importante para a preservação dos recursos naturais. Pequenas mudanças de hábitos podem contribuir para a redução do desperdício e para o uso mais sustentável da água. 💧🌎



🛠️ Tecnologias utilizadas


🐍 Python	Desenvolvimento do programa

🔀 match/case	Estrutura de decisão

💻 VS Code	Desenvolvimento e edição

🐙 GitHub	Versionamento e armazenamento do projeto

💧 Educação ambiental	Conscientização sobre o consumo de água
